# 360-degree audit package

This folder is an audit-only deliverable. It does not authorize or contain
application refactoring.

Start with [360_AUDIT_MASTER_REPORT.md](360_AUDIT_MASTER_REPORT.md), then use
[28_EVIDENCE_INDEX.md](28_EVIDENCE_INDEX.md) to trace each major conclusion to
actual source/functions/routes/tables and its confidence level.

The supplied scope is preserved as [SOURCE_PROMPT.md](SOURCE_PROMPT.md).
